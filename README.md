# Automated-Beverage-Machine
Arduino-based automatic beverage machine developed and tested in SimulIDE.

## Overview

This project was developed as part of a technical program at ETEC.

The system simulates an automated beverage vending machine using an Arduino Uno. Users can select different drinks through buttons, while sensors and actuators control the preparation process.

The entire project was designed and tested in Proteus simulation software.

## Features

- Coffee selection
- Coffee with milk selection
- Cappuccino selection
- Hot chocolate selection
- Cup detection sensor
- Temperature monitoring
- LCD status display
- Automatic ingredient dispensing
- Door open/close control

## Hardware Components

- Arduino Uno
- 16x2 LCD Display
- Temperature Sensor
- Detection Sensor
- Solenoid Valves
- Push Buttons
- 5V Power Supply

## Software

- Arduino IDE
- C/C++
- SimulIDE

## How It Works

1. The user places a cup in the machine.
2. The cup sensor detects the cup.
3. A beverage is selected through the control buttons.
4. The Arduino activates the corresponding valves.
5. The LCD displays system information.
6. The beverage is prepared automatically.
